# Security Policy & Vulnerability Reporting

RFeX Technology takes security and user privacy seriously. RFeX Drive Lite operates under a strict **100% On-Device Privacy Guarantee**, transmitting zero subscriber metrics or location telemetry to external servers.

---

## 1. Supported Versions

| Version | Supported |
| :---: | :---: |
| 1.0.0 (Build 1) | YES |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leakage in RFeX Drive Lite, please report it privately:

- **Email:** `security@rfex.app`
- **PGP / Secure Channel:** Available upon request via `security@rfex.app`
- **Website:** https://rfex.app/security

Please include:
1. Application version and device hardware/Android OS version.
2. Step-by-step reproduction instructions or proof of concept.
3. Description of potential impact.

**Do NOT:**
- Publicly disclose vulnerabilities in public GitHub issues before an official fix has been coordinated.
- Include personal subscriber data (IMSI, phone numbers), real customer site databases, or signing private keys in vulnerability reports.

We commit to acknowledging reports within 48 hours and providing coordinated remediation timelines.
