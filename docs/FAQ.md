# Frequently Asked Questions

**Why do I see N/A?** Android or the modem may not report that field; the app must not fabricate measurements.

**Why are some 5G or neighbor readings absent?** Availability depends on device, operator, SIM, permissions and radio state.

**Can I record drive or indoor tests?** Lite provides local survey workflows with edition limits and supported CSV export.

**Do online maps work offline?** Not without already permitted cached content. The grid view is not an offline license for a map provider's imagery.

**Who runs the speed-test service?** OpenSpeedTest, an external provider, hosts the optional widget.

**Is the Android source available here?** No; first-party code is proprietary and maintained privately.

**Is v1.0.0 fully certified?** See [release status](release/RELEASE_STATUS.md); independent binary and provider verification remain pending.
