# RFeX Drive Lite — Datasheet

**App ID:** `com.rfex.drive.lite` • **Planned version:** 1.0.0

| Module | Capability |
| --- | --- |
| Cellular | Android-reported 2G/3G/4G/5G serving/neighbor data |
| RF measurements | Reported RSRP, RSRQ, SINR and channels where available |
| RF charts | Signal trend displays |
| Outdoor | Map, local measurement recording and CSV export |
| Indoor | Floorplan/sketch and survey points |
| Site overlays | User-imported CSV sites and sectors |
| Network test | User-initiated OpenSpeedTest hosted widget |

Candidate engineering limits: five active minutes for outdoor sessions, three for indoor and a 100-site CSV preview; verify exact behavior before representing them as final specifications. Minimum SDK 26 and target SDK 36 are documented candidate settings, not independently verified binaries.
