# RFeX Drive Lite — User Manual

## Start and permissions
Install from an authorized source. Grant Android location or phone-state permissions only as needed. Denied or restricted access can reduce the information available to the app.

## RF dashboard
Inspect your serving cell, reported neighbors and radio measurements. Not every phone or network exposes every band, channel, cell ID or RF metric. An unavailable value is shown as N/A.

## Outdoor surveys
Select an available map layer or grid; start a user-initiated recording; review points and save a local session. Export supported CSV through the Android document picker. The candidate Lite outdoor time limit is five active minutes and requires final-binary verification.

## Indoor surveys
Import or sketch a floorplan, start a walk, select a position and pin an available RF observation. Pins are relative to the floorplan—not automatically GPS coordinates. Export local observations as supported. The candidate indoor limit is three active minutes.

## Sites
Use a local CSV to load site locations and sector information where supported. Do not import customer datasets into public demonstration material.

## Speed testing
The optional OpenSpeedTest hosted widget is user-initiated. Opening it communicates with an external provider; testing consumes mobile/Wi-Fi data. Results are provided by the widget and are separate from RF telemetry.
