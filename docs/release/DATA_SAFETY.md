# Google Play Data Safety — Final Verification Required

**Not approved for copy/paste into Play Console.** Google's Data safety definition of collection generally concerns user data transmitted off device, including SDK and WebView data. Local-only processing does not itself count as collected.

Before completing the form, inspect final binary permissions, actual telemetry and location transfers, map and speed-test hosts, embedded ads/analytics/consent SDKs, security/HTTPS, backups and deletion workflows.

Reference: https://support.google.com/googleplay/android-developer/answer/10787469

**Do not repeat either historical contradictory Yes/No declaration until verified.**
