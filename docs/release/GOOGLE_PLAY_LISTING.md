# RFeX Drive Lite — Google Play Listing Draft

**Application name:** RFeX Drive Lite  
**Application ID:** `com.rfex.drive.lite`

**Short description:** Cellular signal monitor, RF maps, and indoor/outdoor field surveys.

**Full description:**

RFeX Drive Lite helps users inspect Android-reported cellular signal information on supported 2G, 3G, 4G LTE and 5G NR networks. Explore available serving and neighboring cells, RF readings and charts. Record short outdoor measurement sessions with map overlays and export supported CSV data. For indoor surveys, import or sketch a floorplan and pin RF readings. Import local cell-site CSVs to view available sector overlays.

An optional OpenSpeedTest Public hosted widget provides user-initiated connection testing.

Not all parameters are available on every device or network. Online maps and speed testing require connectivity.
